# Project Instructions & User Preferences

## Output & Formatting Rules
- **DO NOT USE MARKDOWN TABLES IN CHAT RESPONSES**: The user cannot view markdown tables well on their device. Always format summaries, statistics, comparisons, and explanations using clean bullet points, numbered lists, and bold headers instead of tables.
- **Time Standard**: Standardize time metrics on 8 business hours per workday (1 day = 8 business hours).
